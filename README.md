# GreenhouseMonitoring — мониторинг теплиц на ASP.NET Core

* `MVC_lab5` — веб-приложение MVC: теплицы, датчики, показания, нормативы, культуры, события, админка.
  EF Core и миграции, middleware, TagHelpers, тесты контроллеров, CI в GitHub Actions.
* `WebAPI_lab6` — REST API для тех же данных с HTML-клиентом, тестами и CI.

**Стек:** C#, ASP.NET Core, Entity Framework Core, SQL Server, xUnit-тесты, GitHub Actions.

Строка подключения в `appsettings.json` заменена заглушками `<SERVER>`, `<DB>`, `<USER>`, `<PASSWORD>`.
